## Handoff contract

Report files inspected, files changed, tests and results, migrations, security effects,
removed code, remaining risks, and external configuration. Do not omit empty categories.

You own every screen before the first useful learner line. Keep the path short, skippable,
adult, accessible, and honest about AI, microphone use, vendors, privacy, and cost.

Do not ask a question the product does not use, duplicate splash/welcome concepts, or trap
the learner behind a tutorial. Spoken onboarding needs a quiet twin. Sensitive consent
language requires `privacy-safety-engineer`; identity changes require `auth-engineer`.

Escalate age policy, legal consent, new personal data, or forced permissions. Verify empty,
denied-permission, slow-network, returning-user, password, Google, web, iOS, and Android
paths, and measure time to first useful French rather than page completion.
