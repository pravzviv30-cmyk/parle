## Closely checked setup sources

- [Be My Eyes official setup](https://support.bemyeyes.com/hc/en-us/articles/360005536558-Getting-started-with-Be-My-Eyes): the role is chosen before role-specific setup, and language and permission steps have a purpose. Luvani uses a personal reason before a plan and asks for the microphone only when speaking is chosen.
- [Whatnot official account guide](https://help.whatnot.com/hc/en-us/articles/40940443487629-Create-a-Whatnot-account): multiple account methods are documented. This guide does not establish an interest-picking onboarding sequence. Luvani preserves a guest practice path rather than asserting an undocumented pattern.
- [NHS App official setup](https://www.nhs.uk/nhs-app/setting-up/): setup and full-access stages are explained separately. Luvani separates a small first experience from age, processing consent, microphone access and account creation.

## Paywall video notes

[User-supplied video](https://www.youtube.com/watch?v=9ypqs_2fAl8). The complete approximately 12-minute automatic transcript was read; it is not reproduced here. Its design advice supports making outcomes understandable before prices, placing the wall after value, using a small number of visible choices, and explaining eligible trial terms. It also discusses adapting the process to the audience, improving visual polish, using substantiated proof, and testing commercial results. These are general recommendations rather than evidence of a conversion uplift for Luvani.

Applied decisions: illustrated free-versus-paid value page; one selected tier with monthly/yearly choices; one optional comparison sheet; selected-product trial details; full billed amount and automatic renewal beside the CTA; clear Not now; existing purchase verification and recovery routes. A returning or unknown-eligibility account receives no free-trial promise. No fake timer, invented rating, or unscheduled reminder was added. The footer now follows the user’s exact copy: “No Commitment, Cancel Anytime”.

[Apple subscription disclosure guidance](https://developer.apple.com/app-store/review/guidelines/#subscriptions) supports describing what a subscription supplies before asking for it. Prices and trial eligibility still come from the store; allowances still come from the server catalogue.

## Orb source and implementation

[Orb UI](https://github.com/exprmntl/orb-ui), reviewed commit `4d8bed99f9c626a88d97e4e3a30e00746b76860d`, is a browser React library, with no SKILL.md in the reviewed tree. The upstream cloud theme and separate input/output concept informed the revision. Its MIT license is included. Luvani uses an original native SVG cloud surface with bounded blur and native transform/opacity animation. It does not install the browser renderer or run an upstream script. The latest user screenshot determines the periwinkle upper field, lavender lower field, luminous cloud horizon and clear centre.

## Verification scope

Actual React Native views were rendered through the web target inside 375×812, 390×844 and 430×932 iframe bounds with safe-area fixtures. These validate content layout in the web renderer; they do not prove native GPU performance, real iOS safe areas, VoiceOver behavior or store purchase completion. Figma state variants and motion were inspected separately. Physical-device checks remain required before release. Responsive geometry is expressed using viewport, safe-area and font-scale policies rather than speculative device names.
