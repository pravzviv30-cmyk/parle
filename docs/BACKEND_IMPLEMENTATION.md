## Architecture after the changes

Keep the managed monorepo, PostgreSQL, distributed Redis limiter and LiveKit architecture. Five independently configured runtime roles share one immutable image:

- API: verified identity, bounded HTTP, authoritative session admission, account operations and scoped worker callbacks.
- Tutor: current database-issued session fence, per-job vendor proxy, bounded queues/safety/cache; no database service credential.
- Practice: durable leased recovery from safe saved learning artifacts, finite generation/retry deadlines and paid dispatch checks.
- Maintenance: reconciliation, room stops, erasure/processor retries, retention and independently encrypted deletion journal.
- Observability: one pinned API-instance exporter; only the distinct metrics credential, private host-network listener in the Linux reference.

The API/practice/maintenance still hold Supabase service-role credentials. RLS protects app callers, but does not constrain those trusted credentials. Owner checks, parent-identity locks, input bounds and closed RPC interfaces remain essential. Dedicated per-service database roles, provider/network egress policies and host secret-manager permissions need separately verified deployment work; do not describe the service-role architecture as complete least privilege.

Session flow is Auth verification → live session check → database allowance/concurrency/daily exposure reservation → reviewed paid operation reservation → signed join metadata → atomic worker claim → scoped paid resume → each real vendor effect admitted → acknowledged learning checkpoint → frozen learner billing cutoff → bounded optional enrichment → durable completion/receipt → reconciliation after lost processes or ACKs. Neither join-token expiry nor Redis is settlement authority. Active cancellation holds capacity until confirmed termination/reconciliation.

## Paid transport compatibility

Production supports reviewed Anthropic/OpenAI hosted brains, Nova3 PCM16 mono16k streaming with French/multilingual phase reset, ElevenLabs pinned HTTP PCM TTS, Deepgram REST transcription and Speechace text-v9 scoring. Providers/configurations without exact immutable quote bindings refuse before paid traffic. Anthropic/OpenAI SDK and outer retries consume separate effects; response streams have finite bytes and a hard headers/body deadline. The proxy replaces dummy SDK credentials with server-held vendor credentials and forbids arbitrary destinations, redirects, paths, parameters or GET prewarm probes. Production boot does not synthesize unadmitted paid probes.

OpenAI finite activity cache keys are addressing/input, not configuration identity, so persona changes do not exhaust the sixteen-component quote limit. Their actual bytes remain admitted, and quote reviewers must price all input as uncached. Model/output/reasoning/storage/schema/service-tier settings remain bound. Production API/container startup refuses unsupported scorer/TTS keys and ambiguous scorer selection. Standalone paid operator tools have no production admitted adapter and refuse execution.

Each STT connection conservatively reserves the full remaining maximum session duration. Language resets/reconnects need explicit finite matching quote components; one component does not automatically approve32SDK reconnect attempts. Stops use both an abort signal and wall-clock permit check before connection and each forwarded audio frame. Optional analyst failures retain the acknowledged baseline; they never add learner billing time. Paid counters intentionally keep failed/cancelled/uncertain exposure rather than recycling it.

Transient compressed uploads are decoded to measured PCM before admission, using a reviewed hash-pinned executable:2MiB input,30s mono output,5s wall,2children perprocess and bounded allocation/threads/protocols. Unsupported/nonseekable formats refuse explicitly. Local real FFmpeg decoded synthetic fragmented M4A (~1088ms including codec padding) and WebM (1000ms) and rejected31s. This does not prove recorder compatibility on physical devices or the Linux image.
