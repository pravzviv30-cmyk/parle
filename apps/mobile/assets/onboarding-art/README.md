# C2 onboarding illustration assets

These are the approved editable Figma C2 illustrations from file
`sjAwoGinWQKvhGrWbgMO18`, downloaded on 18 October 2026. The SVG files are
original exports. They have not been redrawn or substituted.

`scenes.json` holds the same SVG strings with exact Figma layer positions,
rotations, natural root dimensions and stroke padding. It is consumed by
`src/onboarding/motion/C2Scene.tsx` and by the separate Remotion design study.
The native app animates wrappers around vector layers with its existing
Reanimated engine; no video replaces interactive controls.

The eight compositions are welcome, confidence, focus, time, personal plan,
completion celebration, quietly proud cloud, and account welcome emblem.
Cloud and orange characters move as coherent groups, while hand and expression
layers can respond independently. The shared motion owner handles reduced
motion, focus, backgrounding and account changes. The existing streak flame
retains its separate animation and qualifying-evidence rules.

`small.json` contains the exact goal miniatures and tutor portraits. The source
asset manifests and context captures record Figma provenance; their temporary
download URLs are not runtime sources.
